# Raunak Dey

Personal portfolio: projects, competitions and a combined GitHub and Kaggle activity calendar.

**[raunak-dey.vercel.app](https://raunak-dey.vercel.app/)**

## How it's built

Plain HTML, CSS and JavaScript, with no framework and no build step.

A scheduled GitHub Action refreshes the activity data nightly from the GitHub and Kaggle APIs and commits it only when something changed.

## Running locally

```bash
git clone https://github.com/raunakdey-07/raunakdey-07.github.io.git
cd raunakdey-07.github.io
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
